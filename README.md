# Life of an Evermean: Cosmic Ascension

A 3D first-person survival game built with Three.js and Web Audio, directly inspired by the living tree mimics—**Evermeans**—from *Zelda: Tears of the Kingdom*.

## Features
- **Authentic TOTK Evermean Mechanics**: Start as a baby eyeless pointy-legged tree sprout, skitter across the forest, root yourself into the soil for tree camouflage (`C`), and execute violent downward trunk/head-slam attacks (`Left Click`) that shake the earth and fell timber!
- **Elemental & Animal-Hybrid Species**:
  - **Infernal Fire Evermean**: Charred obsidian bark, burning ember crown, fiery slam.
  - **Stormvolt Lightning Evermean**: Electrified storm timber, chain lightning arc.
  - **Verdant Flora Evermean**: Living moss and blooming vines, hyper-photosynthesis.
  - **Glacial Frost Evermean**: Frosted permafrost wood and icicle needles.
  - **Praying Mantis Evermean**: Tree boughs adapted into razor-sharp wooden raptorial scythe arms with 6 pointy root legs and ambush slashes!
  - **Horned Stag Evermean**: Massive branch antlers for head-ramming.
  - **Arachnid Weaver Evermean**: 8-legged hollow tree crawler.
- **Day-by-Day Cosmic Evolution**:
  - Survive day by day, absorbing daytime sunlight (photosynthesis) and nighttime groundwater.
  - Collect Cosmic Stardust fallen during night meteor showers to achieve **Cosmic Ascension**: transform into an ancient starry World Tree with the **Cosmic Gravity Singularity Slam**!
- **Swimming & Water Physics**: Jump into rivers and lakes—your wooden body floats buoyantly, roots paddle with water splashes, and moisture is restored.
- **Creature Villages**:
  - **Woodcutter Goblin Outpost**: Axe-wielding goblins chopping forest trees—your mortal foes! (Disguise with `C` to let them walk right past).
  - **River Beaverfolk Stilt Village**: Friendly riverside wooden settlement with water wheels.
- **Evermean Civilization Building**: Press `B` to place Heart Trees, Sapling Incubators (awakening baby Evermean followers), Living Bramble Walls, and Sap Basins.
- **Full Menu Systems**:
  - Continue, New Game (with 3D Evermean Customizer Studio), Save (4 slots), Load, Export (`.json`), Import (`.json`), and comprehensive Graphics/Audio Settings.

## Running the Game
```bash
npm install
npm run dev
```
Open your browser to: `http://localhost:3000/`
